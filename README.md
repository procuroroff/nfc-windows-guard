## 📖 Описание проекта

**NFC Windows Guard** — специализированный комплекс безопасности для Windows, превращающий USB NFC-считыватель **ACS ACR122U** в аппаратный ключ доступа к компьютеру.

При включении ПК, блокировке системы или нажатии сочетания **`Win + L`** поверх системы на **всех подключенных мониторах** активируется защитный экран. До прикладывания зарегистрированной NFC-карты (Mifare Classic, Ultralight, NTAG213/215/216, транспортные карты Тройка/Стрелка, пропуска, брелоки) доступ к рабочему столу и ввод штатного пароля заблокированы.

### 🎯 Новые возможности и исправления

* 🖥️ **Поддержка нескольких мониторов (Multi-Monitor Support)**:
  * Защита автоматически определяет все подключенные дисплеи через Windows API `EnumDisplayMonitors`.
  * Основной экран отображает интерактивный центр считывателя с анимацией и статусом.
  * Все второстепенные мониторы полностью перекрываются защитными экранами-заглушками в тон выбранной темы (`TopMost`, без рамок, перехват фокуса).
* 🔒 **Интеграция с ручной блокировкой `Win + L` и сессиями**:
  * В состав программы входит **резидентная фоновая служба (Демон)** (`nfc_guard/daemon.py`).
  * Служба работает в системном трее Windows и использует `WTSRegisterSessionNotification` для отслеживания событий `WTS_SESSION_LOCK` и `WTS_SESSION_UNLOCK`.
  * При нажатии **`Win + L`** или **`Ctrl + Alt + L`** защитный экран мгновенно закрывает все мониторы!
  * При выходе из спящего режима или экрана блокировки Windows сразу требует приложить NFC-карту.
* 🎨 **Интерактивный предпросмотр тем в реальном времени**:
  * Панель управления содержит карточку **Live Preview** — при переключении тем цвета, акценты, карточки и кнопки мгновенно меняются прямо в окне настроек.
  * Пресеты: **Cyberpunk (Неон)**, **Тёмная (Dark Modern)**, **Матрица (Matrix Hacker)**, **Полночь (Midnight Blue)**, **Светлая (Clean Minimal)**, **Красная тревога (Red Alert)**.
  * Корректная адаптация светлых и темных оттенков.
* 🔢 **Система попыток (3 попытки по умолчанию)**:
  * При каждой неверной карте счетчик уменьшается (`3` → `2` → `1` → `0`).
  * После исчерпания попыток оверлей снимается и активируется штатный экран входа Windows (`LockWorkStation`).
* 🔊 **Аппаратная обратная связь считывателя ACR122U**:
  * Зуммер и двухцветный светодиод ридера (успех / ошибка / тревога).
* 💳 **Белый список карт и сканер в реальном времени**:
  * Добавление карт в один клик по кнопке *«📡 Сканировать с ридера»*.
* 🛡️ **Экстренный мастер-PIN**:
  * Быстрый аварийный вход по нажатию `Esc` на случай утери карты.

## ⚙️ Установка и Быстрый старт

### 1. Установка зависимостей
Запустите `setup_environment.bat` или выполните:
```bash
pip install -r requirements.txt
```

### 2. Добавление вашей карты в Центре Управления
Запустите [open_settings.bat](open_settings.bat):
1. Перейдите во вкладку **«💳 Ключ-карты»**.
2. Нажмите **«📡 Сканировать с ридера»** и приложите карту/брелок к ACR122U.
3. Введите название (например, *«Мой ключ»*) и нажмите **«+ Добавить»**.
4. Во вкладке **«🎨 Темы и Оформление»** выберите понравившуюся тему (например, *Матрица* или *Cyberpunk*) — результат отобразится в карточке предпросмотра.

### 3. Запуск фоновой службы (Win+L и автоблокировка)
* Нажмите кнопку **«▶ Запустить службу»** во вкладке **«🛡️ Безопасность и Служба»** (или запустите [start_daemon.bat](start_daemon.bat)).
* Включите чекбокс **«Запускать фоновую службу при старте Windows»** (или запустите [install_autostart.bat](install_autostart.bat)).
* В системном трее Windows (возле часов) появится иконка щита с замком.

### 4. Проверка работы
* **Проверка Win+L**: Нажмите `Win + L` или сочетание `Ctrl + Alt + L` — экраны мгновенно заблокируются с требованием приложить карту!
* **Проверка второго монитора**: Посмотрите на второй монитор — он надежно закрыт защитным экраном-заглушкой.
* **Приложите карту**: Система снимет блокировку и вернет рабочий стол.

## 🛡️ Безопасность и Резервный доступ (Fail-Safe)

1. **Что делать, если ридер отключен или карта утеряна?**
   * Приложите любую неподходящую карту 3 раза — программа переведет компьютер на штатный экран Windows для ввода пароля учетной записи.
   * Либо нажмите `Esc` на экране блокировки и введите мастер-PIN, установленный вами в настройках.
2. **Как выключить службу?**
   * Кликните правой кнопкой мыши по иконке щита в трее и выберите *«Выход из защиты»*, либо нажмите *«⏹ Остановить»* в Центре Управления.

## 📖 Описание проекта

**NFC Windows Guard** — это специализированное приложение безопасности для Windows, интегрирующее USB NFC считыватель **ACS ACR122U** в качестве физического ключа доступа к компьютеру.

При загрузке компьютера или блокировке системы поверх экрана отображается полноэкранный защитный оверлей, требующий прикладывания зарегистрированной NFC-карты (Mifare Classic, Ultralight, NTAG213/215/216, транспортные карты Тройка/Стрелка, пропуска, брелоки и т.д.). До прикладывания валидной карты доступ к системе и ввод штатного пароля заблокированы.

### 🎯 Ключевые возможности

* 🔑 **Аппаратная авторизация по NFC**: Мгновенное считывание UID карты через стандарт PC/SC и APDU (`FF CA 00 00 00`).
* 🔒 **Полноэкранный защитный экран (Lock Screen)**:
  * Блокирует системные комбинации клавиш (`Alt+Tab`, `Win`, `Alt+F4`, `Alt+Esc`, `Ctrl+Esc`).
  * Временно отключает Диспетчер задач (`DisableTaskMgr`) на время блокировки.
  * Работает в режиме `TopMost` поверх всех окон.
* 🔢 **Система попыток (3 попытки по умолчанию)**:
  * При каждой неверной карте счетчик уменьшается (`3` → `2` → `1` → `0`).
  * После исчерпания попыток программа завершает блокировку и вызывает штатную блокировку Windows (`LockWorkStation`), переводя пользователя на стандартный экран ввода пароля Windows.
* 🔊 **Аппаратная обратная связь считывателя ACR122U**:
  * Приятный короткий сигнал зуммера и зеленый светодиод при успешном входе.
  * Двойной предупреждающий звуковой сигнал и красный светодиод при чужой карте.
  * Длинный сигнал тревоги при исчерпании лимита попыток.
* 🎨 **Полная кастомизация оформления (Темы)**:
  * Пресеты: **Cyberpunk (Неон)**, **Тёмная (Dark Modern)**, **Матрица (Matrix Hacker)**, **Полночь (Midnight Blue)**, **Светлая (Clean Minimal)**, **Красная тревога (Red Alert)**.
  * Настройка заголовков, текстов подсказок, индикации UID и счетчика.
* 💳 **Управление белым списком карт**:
  * Сканирование карт в реальном времени прямо со считывателя (кнопка *«Сканировать с ридера»*).
  * Присвоение человекопонятных имён (например, *«Основной ключ-брелок»*, *«Запасная карта»*).
  * Возможность временного отключения карты без удаления.
* 🛡️ **Экстренный мастер-PIN**:
  * Возможность задать резервный PIN-код на случай утери карты или поломки считывателя.
* 📋 **Журнал аудита (Audit Log)**:
  * Детальный лог всех событий с временными метками: успешные входы, отказы, UID карт, переходы к штатному входу.
* 🚀 **Интеграция с автозагрузкой Windows**:
  * Включение и отключение автозапуска в один клик через реестр (`Run`).

## ⚙️ Установка и Настройка

### Шаг 1. Системные требования
1. **ОС**: Windows 10 или Windows 11 (x64).
2. **Оборудование**: USB-считыватель **ACS ACR122U** (подключен по USB). Драйвер обычно устанавливается автоматически через Windows Update (CCID).
3. **Python**: Python 3.10 или новее.

### Шаг 2. Клонирование и установка зависимостей
Склонируйте репозиторий:
```bash
git clone https://github.com/procuroroff/nfc-windows-guard.git
cd nfc-windows-guard
```

Установите зависимости (или запустите `setup_environment.bat`):
```bash
pip install -r requirements.txt
```

### Шаг 3. Первичная настройка (Панель управления)
Запустите центр управления:
```bash
open_settings.bat
# или
python main.py --settings
```

1. Перейдите во вкладку **«💳 Ключ-карты»**.
2. Убедитесь, что считыватель подключен по USB.
3. Нажмите **«📡 Сканировать с ридера»** и приложите вашу карту или брелок к ACR122U.
4. UID будет распознан и подставлен автоматически. Введите понятное название (например, *«Мой ключ»*) и нажмите **«+ Добавить»**.
5. *(Рекомендуется)* Во вкладке **«🛡️ Безопасность и Запуск»** задайте экстренный **Мастер-PIN** (на случай утери карт).
6. Включите галочку **«Запускать экран блокировки при включении компьютера»** (или запустите `install_autostart.bat`).

### Шаг 4. Тестирование экрана блокировки
Нажмите в панели управления кнопку **«🔒 Тест экрана блокировки»** или запустите:
```bash
start_lock.bat
# или
python main.py --lock
```
* Приложите зарегистрированную карту — экран окрасится в зеленый, считыватель издаст сигнал, и блокировка снимется!
* Приложите постороннюю карту — отобразится предупреждение об ошибке, считыватель подаст сигнал ошибки, количество попыток уменьшится.
* После 3 неудачных попыток система автоматически завершит оверлей и перейдет к штатному входу Windows (`LockWorkStation`).

## 🛡️ Безопасность и Резервный доступ (Fail-Safe)

1. **Что делать, если карта потеряна или ридер отключен?**
   * На экране блокировки нажмите кнопку **«Штатный вход Windows»** (если включена в настройках) либо введите 3 раза любую карту — оверлей закроется и откроет стандартное поле ввода пароля учетной записи Windows.
   * Нажмите клавишу `Esc` и введите резервный **Мастер-PIN**, заданный вами в настройках.
2. **Как удалить программу из автозагрузки при сбое?**
   * Запустите `uninstall_autostart.bat` либо удалите запись `NFCWindowsGuard` из раздела реестра:
     `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
